# Product VIS V2.1B

A Vercel-ready realtime product visualization studio. The included 2015 Rocket Bunny Honda NSX GLB loads locally on first visit and can be replaced with any binary GLB.

## Validate

```bash
npm install
npm run check
npm run test:smoke
```

Run locally with `npm run dev`. The application is a Vite static build and deploys through the included `vercel.json`.

See `CHANGELOG_V2.1B.md` for the release changes.
